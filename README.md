# GameTextReader Layouts

Shared layouts for GameTextReader: where its Read Areas go on the screen, with their hotkeys, automations and Text Rules.

- **Submissions** are issues here (the label `layout submission`). Use "Submit a Layout" in GameTextReader, which makes the file and
  opens the form.
- **Shared layouts** are the files in `layouts/`, in a folder for each kind (`game`, `program`, `other`). `layouts/index.json` is the
  list the app reads. Only layouts that were looked at are put here.

Nothing in a layout is run: it is data the app reads.
